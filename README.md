# Stock audit scripts and reports

Backup of KPOPTOWN stock comparison scripts and exported reports for FANS SHOP, Weverse Shop, SMTOWN &STORE, and other suppliers.

Reports are snapshots at their recorded collection times. They include stock comparisons, reverse comparisons, and price update results. Read each report's notes and summary before using it.

Scripts depend on the original local browser/runtime setup and authenticated sessions. Credentials, cookies, tokens, browser profiles, raw admin pages, dependency folders, and duplicate ZIP archives are excluded. No live store changes are performed by this backup.
